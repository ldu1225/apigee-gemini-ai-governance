아키텍처 동작 설명

현업 개발자는 별도의 토큰 수집 코드를 작성할 필요 없이, 기존 Gemini API 규격 그대로 접속 주소만 Apigee Gateway로 바꾸고 부서 토큰(Authorization: Bearer ...)을 헤더에 넣어 호출합니다.

💡 위 4개 단계 카드 또는 6개 탭 버튼을 클릭하면 해당 단계의 실제 코드로 즉시 전환됩니다. 
POST /v1/models:generateContent HTTP/1.1
Host: apigee-gateway.YOUR_GCP_PROJECT_ID.cloud.goog
Authorization: Bearer dept-a-rnd-token-2026   <-- [부서 식별용 API 토큰]
Content-Type: application/json

{
  "model": "gemini-3.1-pro",                      <-- [호출 희망 모델명]
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "엔터프라이즈 마이크로서비스 장애 대응 매뉴얼 및 아키텍처 설계 기준 요약해줘" }
      ]
    }
  ]
}
